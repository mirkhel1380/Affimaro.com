# Affimaro interface preferences

- The owner requires mobile layout to be considered in every interface change.
- Check affected screens at 320 px, 390 px and 768 px, plus a desktop width, using the supported browser tools. A same-origin local iframe can provide a narrow viewport when browser resizing is unavailable. Remove temporary QA pages before packaging or publishing.
- Check for horizontal page overflow, readable text, usable form fields, touch targets, dropdowns and long labels. Preserve the light and dark themes.
- If a viewport cannot be checked visually, record that limit accurately and continue the checks that are available.
- Keep product copy in English and communicate with the owner in right-to-left Dari.
